# 测试

在仓库根目录串行运行。`AXC_PYTHON` 指向装好依赖的 Python；用引擎源码时同时设置 `PYTHONPATH`。

```sh
npm run typecheck                 # TypeScript（含未使用变量检查）
npm test                          # 前端单测（vitest）
.venv/bin/python -m pytest tests/ -q
AXC_PYTHON=.venv/bin/python npm run test:browser
```

## 各项覆盖

| 检查                        | 内容                                                                                                                                                                                                                                                        |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tests/*.test.ts(x)`        | 快照与事件合并、订阅生命周期、IME、发送失败恢复草稿、附件失败 / 取消 / 重试、插话与排队、分支树、开分支选择、归档与删除确认、归档页分组与恢复、模型级联与能力过滤、密钥掩码、推演表单校验与模式字段                                                         |
| `tests/test_*.py`           | 范围与权限、命令幂等、会话持久化与重启、分叉（任意回复、分支历史）、归档级联、提供商加密与连通测试、Agent CRUD / 校验 / 导出、技能导入与路径穿越拦截、知识库文档、图谱 CRUD 与持久化、插件目录、评估、附件                                                  |
| `scripts/browser-check.mjs` | 用 fixture 模型启动真实引擎和前端，点一遍全部分区：提供商（页面不出现明文 Key）、Agent 级联与校验、技能、知识库上传、图谱、工具目录、附件对话、嵌套分叉、深色、推演 / 采访 / 报告、评估、720 / 390px 嵌入抽屉；截图写入 `AXC_SHOTS`（默认 `docs/evidence`） |
| `scripts/real-check.mjs`    | 针对已启动、已在界面配好真实模型的工坊逐项验收：多轮对话、图谱与知识库工具、附件、插话、开分支与分支上下文、停止、归档与恢复删除、推演、评估、390px 抽屉                                                                                                    |
| `scripts/package-check.mjs` | `npm pack` 后在 React 18 / 19 的干净项目里安装、`tsc` 类型检查并挂载组件                                                                                                                                                                                    |

`real-check.mjs` 会在你的数据里创建以 `验收` 开头的 Agent、会话、推演和评估，跑完可在界面里清理。

```sh
node scripts/real-check.mjs http://127.0.0.1:5173
```
